SpendWise Workspace Migration Manual

Device Transfer & Environment Setup Guide

Complete guide to restoring all git-ignored environment configs, system prerequisites, package dependencies, and development services onto your new laptop.

Monorepo: Turborepo + pnpm workspace
Node.js: >= 20.11.0 (Recommended 22.x LTS)
Package Manager: pnpm 9.15.4
1 System Prerequisites & Tool Installation
Before installing dependencies: Make sure Node.js, pnpm, and Git are properly installed and added to your new system's PATH.
Step 1.1
Node.js (v20+ or v22 LTS)

Download from official site or via nvm/winget.

winget install OpenJS.NodeJS.LTS
# Verify
node -v
Step 1.2
pnpm (v9.15.4)

Required monorepo package manager.

npm install -g pnpm@9.15.4
# Or enable corepack
corepack enable
Step 1.3
Global CLI Tools (Optional)

NestJS CLI, Turborepo & Expo.

npm install -g turbo @nestjs/cli expo-cli
2 Restoring Git-Ignored Environment Files (.env)
CRITICAL: Git does not track .env files. You must manually recreate each of the 4 environment files below with their exact keys and values in your new repository folder.
Root Workspace Environment
SpendWise/.env

Contains ports, default base URLs, and Google SMTP configuration for email verification.

# Workspace-level defaults
NODE_ENV=development
PORT=4000
API_PORT=4000
WEB_PORT=3000
MOBILE_API_URL=http://localhost:4000/api/v1
API_BASE_URL=http://localhost:4000/api/v1

# Google SMTP Email Verification
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-gmail-app-password
SMTP_FROM_EMAIL=your-email@gmail.com
SMTP_FROM_NAME=SpendWise
EMAIL_VERIFICATION_CODE_TTL_MINUTES=10
EMAIL_VERIFICATION_RESEND_COOLDOWN_SECONDS=60
Backend API Environment
SpendWise/apps/api/.env

Contains MongoDB Atlas connection string, JWT secrets, and Google Gemini AI API Key.

NODE_ENV=development
PORT=4000
MONGODB_URI=mongodb+srv://<db_user>:<db_password>@spendwise.c2i5amu.mongodb.net/
JWT_ACCESS_SECRET=change-me-access-secret
JWT_REFRESH_SECRET=change-me-refresh-secret
JWT_ACCESS_TTL=15m
JWT_REFRESH_TTL=7d
AI_PROVIDER=gemini
GOOGLE_GENERATIVE_AI_API_KEY=your-gemini-api-key-here
Web Frontend (Next.js) Environment
SpendWise/apps/web/.env

Contains Next.js API client endpoint, cookie config, and Better Auth settings.

NEXT_PUBLIC_API_URL=http://127.0.0.1:4000/api/v1
NEXT_PUBLIC_APP_NAME=SpendWise
AUTH_COOKIE_NAME=spendwise_access_token
BETTER_AUTH_SECRET=replace-with-a-long-random-string
BETTER_AUTH_URL=http://localhost:3000
GOOGLE_GENERATIVE_AI_API_KEY=
Mobile App (Expo / React Native) Environment
SpendWise/apps/mobile/.env

Contains Expo public endpoints (use your local machine LAN IP when testing on physical phone).

EXPO_PUBLIC_API_URL=http://localhost:4000/api/v1
EXPO_PUBLIC_APP_NAME=SpendWise
3 Step-by-Step Installation & Build Instructions
Step Action Command / Script Notes
01 Clone & Enter Repo git clone <repo_url> SpendWise
cd SpendWise		 Pull latest main/dev branch.
02 Create .env Files Place the 4 .env files from Section 2 Root, apps/api, apps/web, apps/mobile
03 Install Dependencies pnpm install Installs all monorepo workspace packages and links.
04 Build Internal Packages pnpm --filter @spendwise/shared build
pnpm --filter @spendwise/ai build		 Compiles shared TypeScript definitions and AI SDK.
05 Run Full Build (Optional) pnpm build Verifies all packages, API, web, and mobile build without type errors.
06 Seed Database (Optional) pnpm --filter @spendwise/api seed Populates MongoDB with sample expense categories and dummy data.
4 Starting Dev Servers
Monorepo All-in-One Start All Services Concurrently 
pnpm dev

Runs Turborepo which launches NestJS API, Next.js web app, and Expo dev server simultaneously.

Backend API Only Port 4000 (Swagger/Endpoints) 
pnpm --filter @spendwise/api dev

API live at http://localhost:4000/api/v1

Web Frontend Only Port 3000 (Next.js Dashboard) 
pnpm --filter @spendwise/web dev

Dashboard live at http://localhost:3000

Mobile App Only Expo DevTools 
pnpm --filter @spendwise/mobile dev

Scan QR code with Expo Go app (iOS / Android).

6 New Device Migration Checklist
1. Node.js (v20+) and pnpm (v9.15.4) installed and accessible in terminal.
2. Git repository cloned to local drive.
3. Created root .env with SMTP credentials.
4. Created apps/api/.env with MongoDB URI & Gemini API Key.
5. Created apps/web/.env with API endpoints.
6. Created apps/mobile/.env with API endpoints.
7. Ran pnpm install and confirmed all node_modules resolved.
8. Ran pnpm dev and verified API (port 4000) and Web (port 3000) respond.
